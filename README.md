# HOSPITAL-MANAGEMENT-SYSYTEM
Production-ready CLI Hospital Management System built with Python and MySQL. Features a real time, dynamic Emergency Triage Module leveraging SQL priority queues order by severity and arrival date for automated patient prioritization. Fully ACID-compliant with robust CRUD operations and modular architecture.
It can Show Patient's report, Add/Remove doctors, add new patients, Give an appointment for patient, add/update bill.
In emergency triage the patient with highest priority is treated first and then after treatment patient is removed from the queue.
